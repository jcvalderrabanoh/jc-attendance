# jc-attendance · Checador

Registro de entradas y salidas multicuenta para patrones y empleados. Comparte la
base PostgreSQL de [jc-core](https://github.com/jcvalderrabanoh/jc-core) en su propio
esquema `attendance`, sin tocar el modelo de datos de jc-core.
